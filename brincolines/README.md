# Inflables Brincolines Cartago

Sitio estático (HTML + imágenes) con catálogo, cotizador y reservas por WhatsApp.

- Editar precios / inflables / número: lista `PRODUCTS` y constante `WHATSAPP` al inicio del `<script>` en `index.html`.
- Fotos en `img/` (mismo nombre de archivo para reemplazar).
- Despliegue: Hostinger → Git → rama `main`, directorio `public_html`.
